# 群汇报 · 群聊一键出日报

面向已有本机 Agent 的群主和管理者，将指定群聊整理成有消息依据的日报，并发布到固定群主页。阅读者只需打开链接。

**当前版本：1.0.0a1（Alpha）。** 本地功能和发布接口已实现，尚未完成真实群连续试用及生产上线。域名：qunhuibao.com。

## 产品形态

- CLI：材料导入、已有微信CLI适配、引用校验、固定模板网页和发布。
- Skill：指导本机Agent阅读材料、提炼热点/方法/资源/通知/问答/精彩对话，选择原话；统计和词云由程序计算。
- 发布服务：邀请发布者、账号隔离、固定群主页、日期历史、修改、撤回和版本恢复。

不接受任意HTML托管。完整聊天留本机，发布包只包含日报、选中的原话和统计。默认遮盖常见联系方式，保留昵称及资源链接。已有微信CLI仍需本机授权，不保证适配全部微信版本。

## 安装

需要Python 3.10或更新版本。在仓库根目录运行：

```sh
python -m pip install -e .
qunhuibao doctor
```

将skills/qunhuibao复制到所用Agent的Skill目录。具体命令见[运行指南](docs/quickstart.md)和[数据契约](docs/contract.md)。Node仅用于开发测试，不是CLI运行依赖。

## 开发验证

```sh
python -m unittest discover -s tests -v
npm ci
npm test
```

长图自动测试覆盖控制分支，不能代替真实浏览器视觉验证。微信新适配、媒体文件关联、不同Agent后台调用、SMTP和生产部署需按运行环境联调。

## 边界

群汇报自身未内置付费模型；宿主Agent可能产生订阅或API费用。开发服务默认监听本机，不应直接暴露到公网。生产环境应配置HTTPS、进程托管、限流及备份，并满足部署地区适用要求。

本仓库为独立的群汇报项目，使用新的Git历史。旧群报告历史单独备份，不带入本仓库；旧部署不作为当前产品上线入口。
